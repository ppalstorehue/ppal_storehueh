# ppal_store

Landing page de ppal_store: hoodies, camisas, perfumes y AirPods, por mayor y menor.

Es una sola página (`index.html`) con HTML, CSS y JavaScript. Las fotos ya están incluidas dentro del archivo.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `ppal_store`), público.
2. Sube estos archivos: `index.html`, `README.md` y `.nojekyll`.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
5. Espera uno o dos minutos. La página quedará en `https://TU-USUARIO.github.io/ppal_store/`.

## Cambiar fotos

Las fotos están al final de `index.html`, en el listado `IMAGENES`. Para cambiar una, reemplaza su valor por la ruta de otra imagen (por ejemplo `"img/mi-foto.jpg"`) y sube esa imagen al repositorio.
